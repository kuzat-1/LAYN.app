# LAYN Brand Pack

Единый официальный набор брендинга для мобильного приложения LAYN.

## Главный стиль
- Wordmark: `LAYN▶`
- `LAYN`: тёмно-серый / charcoal glass, без фиолетовой заливки.
- `▶`: фирменный фиолетовый glass/play.
- Общий стиль: dark glass, premium, minimal.

## Файлы
- `layn_header_logo.svg` — основной горизонтальный логотип для верхней шапки.
- `layn_play_icon.svg` — фирменный знак ▶.
- `layn_app_icon.svg` — иконка приложения 1:1.
- `brand_tokens.json` — цвета и размеры.
- `AGENT_INSTRUCTIONS.md` — точное ТЗ для агента.

## Размер шапки
Рекомендуемый размер в Flutter: **115 × 32 dp**.
Не растягивать пропорции. Выравнивание по вертикальному центру AppBar/toolbar.
