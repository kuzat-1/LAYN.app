# AGENT INSTRUCTIONS — LAYN BRAND INTEGRATION

## Цель
Интегрировать этот бренд-пакет во ВСЁ мобильное Flutter-приложение LAYN и заменить старый логотип/брендинг единым стилем.

## ВАЖНО
Не создавать новый логотип самостоятельно и не менять форму `▶`.
Использовать SVG из этой папки как source of truth.
Не использовать старый GreenTuber-логотип, старые зелёные цвета или старые варианты LAYN.

## 1. Верхняя шапка мобильного приложения
Использовать `layn_header_logo.svg`.

Параметры:
- width: 115 dp
- height: 32 dp
- alignment: left + vertical center
- left padding: 16 dp
- не обрезать и не растягивать
- `LAYN` остаётся тёмно-серым стеклянным
- `▶` остаётся фиолетовым

Логотип должен стоять в левом углу верхней шапки. Справа оставить существующие действия приложения (поиск, уведомления, профиль и т.д.).

## 2. App icon / launcher icon
Использовать `layn_app_icon.svg` как исходник.
Сгенерировать необходимые Android/iOS PNG-ресурсы через существующий механизм проекта (например flutter_launcher_icons), если он уже используется.

Основной знак — только `▶` на тёмном стеклянном фоне.
Не помещать слово LAYN внутрь launcher icon.

## 3. Splash screen
На splash использовать `▶` + при необходимости `LAYN` под ним/рядом, но не старый логотип.
Сохранить dark glass стиль и фиолетовый акцент.
Не добавлять голубой, зелёный или розовый брендовый градиент.

## 4. Admin panel
В admin panel использовать тот же `▶` как основной brand icon.
Для desktop/web header допустим `LAYN▶`.
Для компактных мест — только `▶`.
Не придумывать отдельный admin logo.

## 5. Favicon / PWA / web
Использовать `layn_play_icon.svg` или `layn_app_icon.svg` в зависимости от текущей структуры проекта.
16/32/64/128/256 px должны сохранять узнаваемый `▶`.

## 6. UI consistency
Проверить весь Flutter-проект на:
- старый логотип;
- GreenTuber;
- зелёный цвет бренда;
- старый текстовый логотип;
- дублирующиеся logo widgets;
- hardcoded старые asset paths.

Заменить только branding, не ломая функциональность.

## 7. Assets
Добавить assets в pubspec.yaml по существующей структуре проекта.
Не подключать лишние сторонние icon packages только ради логотипа, если SVG достаточно.

Если `flutter_svg` уже есть — использовать его.
Если его нет и проект допускает SVG как asset через текущую архитектуру, выбрать минимальное решение; не переписывать архитектуру проекта без необходимости.

## 8. Header behavior
Логотип не должен влиять на высоту AppBar.
Не увеличивать toolbar из-за logo.
На маленьких экранах сохранять 115×32 dp либо аккуратно уменьшать ширину при конфликте с action buttons, но не растягивать по высоте.

## 9. Проверка
После интеграции проверить:
- Android portrait;
- Android dark theme;
- Android light theme, если он поддерживается;
- маленький экран;
- большой экран;
- admin panel;
- splash;
- launcher icon;
- web/PWA favicon, если присутствует.

Проверить, что нигде не осталось старого GreenTuber/зелёного брендинга.

## 10. Не менять
Не менять без отдельной причины:
- API;
- PostgreSQL;
- scraper;
- video catalog;
- VK player;
- authentication/business logic;
- navigation logic.

Задача этого пакета — централизованно заменить и унифицировать визуальный branding LAYN.

## Definition of Done
1. В шапке приложения отображается `LAYN▶` размером около 115×32 dp.
2. Launcher icon содержит только фирменный `▶`.
3. Splash использует новый LAYN branding.
4. Admin panel использует тот же знак.
5. Favicon/PWA использует тот же знак.
6. Старый GreenTuber/зелёный логотип удалён из интерфейса.
7. Проект собирается без ошибок.
8. Изменения не ломают существующий функционал.
